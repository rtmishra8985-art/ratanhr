┌─────────────────────────────────────────────────────────────────────────────┐
│                    HOW IT WORKS                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. Application calls EmailService method:                                  │
│     await emailService.SendWelcomeAsync(email, name, empId, password)      │
│                                                                             │
│  2. EmailService reads configuration from .env:                             │
│     EMAIL_HOST=localhost (dev) or smtp-relay.brevo.com (prod)              │
│     EMAIL_PORT=1025 (dev) or 587 (prod)                                    │
│     EMAIL_USERNAME, EMAIL_PASSWORD, etc.                                   │
│                                                                             │
│  3. Creates MimeMessage with HTML body:                                     │
│     Subject: "Welcome to HRMS"                                             │
│     Body: Professional HTML template                                        │
│     From: rtmishra8985@gmail.com                                           │
│     To: employee@company.com                                               │
│                                                                             │
│  4. Connects to SMTP server:                                                │
│     Dev: localhost:1025 (MailHog)                                          │
│     Prod: smtp-relay.brevo.com:587                                         │
│                                                                             │
│  5. Establishes TLS/STARTTLS:                                               │
│     Dev: No TLS (MailHog doesn't need it)                                  │
│     Prod: STARTTLS (TLS 1.2+)                                              │
│                                                                             │
│  6. Authenticates (if needed):                                              │
│     Dev: No auth (MailHog doesn't need it)                                 │
│     Prod: Authenticates with Brevo credentials                             │
│                                                                             │
│  7. Sends email:                                                            │
│     Dev: MailHog captures it → viewable at http://localhost:8025          │
│     Prod: Brevo sends it → delivered to recipient                          │
│                                                                             │
│  8. Handles response:                                                       │
│     Success: Logged, health check updated                                  │
│     Failure: Logged (not blocking), health check updated                   │
│                                                                             │
│  9. Returns control to caller:                                              │
│     App continues (email failure doesn't break app)                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
