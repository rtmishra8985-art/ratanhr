1. TIMEOUT PROTECTION ✅
   ────────────────────────
   Code:
     using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(15));
     await client.ConnectAsync(host, port, secOpt, cts.Token);
   
   Why: Prevents hanging if SMTP server is slow or unresponsive
   Benefit: Timeouts properly, app doesn't stall

2. ERROR HANDLING ✅
   ─────────────────
   Code:
     catch (Exception ex)
     {
         _logger.LogError(ex, "Email delivery failed.");
         EmailHealthCheck.LastFailureUtc = DateTime.UtcNow;
         // Don't rethrow — email failure must not break the operation
     }
   
   Why: Email failure is not critical (doesn't block user operations)
   Benefit: Resilient, observable, non-blocking

3. HEALTH CHECK ✅
   ────────────────
   File: EmailHealthCheck.cs
   Endpoint: /health
   
   Shows:
     - Last SMTP connection status
     - Last error (if any)
     - Timestamp of failure
   
   Why: Monitoring can see if SMTP is down
   Benefit: Ops can detect issues before users complain
