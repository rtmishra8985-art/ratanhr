# Historical Session Reports Archive

This folder contains ~220 point-in-time audit/progress/status reports generated
during earlier development and audit sessions (phase reports, test verdicts,
SMTP setup guides, session handoff notes, etc.).

They are preserved for historical reference but are **not** current
documentation and may describe fixes, statuses, or issues that have since
changed. Do not treat any claim in these files as authoritative about the
current state of the code — always verify against the live source, build,
and test results.

Current, maintained documentation lives at the repository root:
- `README.md`
- `CHANGELOG.md`
- `DEPLOYMENT.md`
- `ARCHITECTURE_DOCUMENTATION.md`
- `DEVELOPMENT_SETUP.md`

Archived on 2026-08-22 as part of a repository cleanup pass. Verified via
static search that none of these files are referenced by CI workflows,
Dockerfile, docker-compose files, or scripts before moving.
