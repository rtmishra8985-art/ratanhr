                SMTP TEST FAILED - DIAGNOSIS & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

ERROR: "The transport failed to connect to the server"

CAUSE: Windows CDOSYS cannot reach smtp-relay.brevo.com:587

POSSIBLE REASONS:
  1. Firewall blocking port 587 (most common)
  2. ISP blocking SMTP port
  3. Network connectivity issue
  4. Brevo server temporarily unavailable

═══════════════════════════════════════════════════════════════════════════════
                            SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

SOLUTION 1: CHECK FIREWALL
───────────────────────────

Step 1: Press Windows Key + S
Step 2: Type: Windows Defender Firewall
Step 3: Click: Allow an app through firewall
Step 4: Look for your application or allow port 587

Or: Check if any antivirus is blocking port 587

SOLUTION 2: TRY DIFFERENT PORT
────────────────────────────────

Brevo supports multiple ports:
  - 587 (STARTTLS) - blocked by your firewall
  - 465 (SSL/TLS) - try this instead
  - 25 (plain) - often blocked by ISP

SOLUTION 3: TEST CONNECTIVITY
──────────────────────────────

Open Command Prompt and run:

  telnet smtp-relay.brevo.com 587

If you see: "Could not open connection"
  → Port 587 is blocked

If you see: "220 Brevo"
  → Connection successful!

SOLUTION 4: USE PYTHON (ALTERNATIVE)
──────────────────────────────────────

If firewall is the issue, Python might work better.

Install Python from: https://python.org

Then run:
  cd C:\Users\karun\Downloads\RatanHR_Run8_Final\RatanHR
  python SEND_LIVE_TEST_EMAIL.py
