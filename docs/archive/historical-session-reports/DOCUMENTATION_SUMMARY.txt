                    KEY CONFIGURATION VALUES
═══════════════════════════════════════════════════════════════════════════════

BREVO SMTP SETTINGS:
  SMTP Server: smtp-relay.brevo.com
  SMTP Port: 587
  Protocol: STARTTLS (TLS 1.2+)
  Authentication: Required
  SSL: Disabled (STARTTLS handles encryption)

.ENV CONFIGURATION:
  EMAIL_HOST=smtp-relay.brevo.com
  EMAIL_PORT=587
  EMAIL_USE_SSL=false
  EMAIL_USERNAME=[Brevo username]
  EMAIL_PASSWORD=[Brevo API key]
  EMAIL_FROM_ADDRESS=[Company email]
  EMAIL_FROM_NAME=RatanHR HRMS

DEPLOYMENT OPTIONS:
  Development: localhost:1025 (MailHog)
  Production: smtp-relay.brevo.com:587 (Brevo)
  On-Premise: Any server with internet
  Cloud: AWS, Azure, Google Cloud

                    TROUBLESHOOTING REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Common Issues:

1. Email not sending
   Solution: Check firewall, credentials, internet connection

2. Authentication failed
   Solution: Verify Brevo username/password, create new API key

3. Email in spam folder
   Solution: Use verified domain, configure SPF/DKIM

4. Slow email delivery
   Solution: Normal (2-3 minutes), check Brevo queue

5. Health endpoint shows unhealthy
   Solution: Check logs, restart application, verify credentials

For detailed troubleshooting: See SMTP_EMAIL_CONFIGURATION_COMPLETE_GUIDE.txt
