                        WHAT IF TESTS FAIL?
═══════════════════════════════════════════════════════════════════════════════

ERROR: "DNS Resolution: FAILED"
  Cause: Cannot reach smtp-relay.brevo.com
  Solution: Check internet connection, firewall settings

ERROR: "Port 587: BLOCKED or UNREACHABLE"
  Cause: Firewall or ISP blocking port 587
  Solution: 
    - Check Windows Firewall settings
    - Try different network
    - Contact ISP if port is blocked

ERROR: "Connection: FAILED"
  Cause: SMTP server is down or unreachable
  Solution: Try again in a few minutes

ERROR: "Authentication: FAILED - Invalid username or password"
  Cause: Wrong Brevo credentials
  Solution:
    - Go to: https://app.brevo.com/settings/keys/smtp
    - Regenerate SMTP key
    - Update .env file with new key
    - Run test again

ERROR: "Email Send: FAILED"
  Cause: Various sending issues
  Solution:
    - Check .env configuration
    - Verify email addresses are valid
    - Check Brevo account status
