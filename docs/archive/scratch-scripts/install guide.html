Step 2 — Install PostgreSQL 16

The primary database for RatanHR

1

Download the installer

Download the Windows installer from the official PostgreSQL website.

🐘 Download PostgreSQL 16 for Windows

Choose: Windows x86-64 → Version 16.x

2

Run the installer

Double-click postgresql-16.x-windows-x64.exe and follow the wizard.

  • Installation directory: C:\Program Files\PostgreSQL\16 (default, keep it)
  • Data directory: C:\Program Files\PostgreSQL\16\data (default, keep it)
  • Password: Set a strong password for the postgres superuser — write it down!
  • Port: 5432 (default — do not change)
  • Locale: Default locale
  • Stack Builder: you can uncheck this — not needed
3

Verify the installation

Open Command Prompt or PowerShell and run:

psql --version
# Expected output:
psql (PostgreSQL) 16.x
💡

If psql is not found, add C:\Program Files\PostgreSQL\16\bin to your System PATH (Search → "Environment Variables" → System variables → Path → Edit → New).

4

Install pgAdmin 4 (GUI — already bundled)

pgAdmin was installed alongside PostgreSQL. Find it in the Start menu under PostgreSQL 16 → pgAdmin 4.

Alternatively, download the latest standalone version:

📊 pgAdmin 4 (standalone download)
🔷

Step 3 — Install Visual Studio 2022

Required for the ASP.NET Core backend

1

Download Visual Studio 2022 Community (free)

🔷 Download Visual Studio 2022 Community Edition (free)
2

Select the correct Workloads

When the installer asks "What do you want to install?", tick these:

Under "Individual components" tab → search and tick: .NET 8.0 Runtime and .NET SDK 8.0

Install Npgsql for Entity Framework (NuGet)

Or search in NuGet GUI: right-click project → Manage NuGet Packages → Browse → search Npgsql.EntityFrameworkCore.PostgreSQL

4

Verify .NET SDK

dotnet --version
# Expected output:
8.0.xxx

Step 5 — Create the RatanHR Database

Create the database and run migrations

1

Open psql and create the database

# Option A — psql command line
psql -U postgres

# Inside psql:
CREATE DATABASE ratanhr;
CREATE USER     ratanhr_user WITH PASSWORD 'YourStrongPassword123!';
GRANT ALL PRIVILEGES ON DATABASE ratanhr TO ratanhr_user;
\q
💡

Option B — pgAdmin GUI:
Open pgAdmin → right-click "Databases" → Create → Database → Name: ratanhr → Owner: ratanhr_user

2

Configure the connection string in appsettings.json

Open your ASP.NET Core backend project. Edit appsettings.Development.json:

{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=ratanhr;Username=ratanhr_user;Password=YourStrongPassword123!"
  },
  "Jwt": {
    "Key": "YOUR_SUPER_LONG_SECRET_KEY_MIN_32_CHARS_HERE",
    "Issuer": "RatanHR",
    "Audience": "RatanHR",
    "ExpiryHours": 8
  }
}
⚠️

Never commit appsettings.Development.json with real passwords.
Add it to .gitignore. Use User Secrets for local dev:
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "..."

3

Run Entity Framework migrations

In the Package Manager Console (Visual Studio) or a terminal inside the backend project folder:

# Option A — Package Manager Console (Visual Studio)
Update-Database

# Option B — dotnet CLI (any terminal)
dotnet ef database update

If there are no migrations yet, create the initial one first:

dotnet ef migrations add InitialCreate
dotnet ef database update
4

Verify the database was created

psql -U ratanhr_user -d ratanhr -c "\dt"
# You should see a list of tables (Employees, Users, etc.)

📌 Connection String Quick Reference

Development (localhost)
Host=localhost;Port=5432;Database=ratanhr;Username=ratanhr_user;Password=YourStrongPassword123!
Production (change host/credentials)
Host=your-server;Port=5432;Database=ratanhr_prod;Username=ratanhr_prod_user;Password=ProdPass;SSL Mode=Require

Step 6 — Run RatanHR Locally

Start both the backend API and the React frontend

1

Start the ASP.NET Core backend

Option A — Visual Studio: Open the .sln file → press F5 or click ▶ Run.
The API will start on https://localhost:7001 (or the port in launchSettings.json).

Option B — dotnet CLI:

cd YourProject.API
dotnet run
# API available at: https://localhost:7001/swagger
2

Install frontend dependencies

cd HRMS.SPA.Source
npm install
# Or with pnpm:
pnpm install
3

Configure the API base URL

Create HRMS.SPA.Source/.env.local:

VITE_API_BASE_URL=https://localhost:7001/api
ℹ️

The .env.local file is gitignored. Never commit it. Each developer sets their own local port.

4

Start the React dev server

npm run dev:local
# Or:
pnpm dev:local

# Output:
  VITE v5.x.x  ready in 800 ms
  ➜  Local:   http://localhost:3000/
  ➜  Network: http://192.168.x.x:3000/

Open your browser at http://localhost:3000 🎉

5

Run unit tests (optional)

npm run test              # All unit tests
npm run test:coverage     # With coverage report
npm run typecheck         # TypeScript check
npm run lint              # ESLint
6

Run E2E tests (Playwright)

npm run e2e:install       # First time only — downloads browsers
E2E_BASE_URL=http://localhost:3000 npm run e2e
npm run e2e:report        # View HTML test report
📌

Common Issues & Fixes

!

"psql is not recognized"

Add PostgreSQL bin to PATH:
C:\Program Files\PostgreSQL\16\bin
Search Windows → "Edit the system environment variables" → Environment Variables → System → Path → Edit → New

!

Port 5432 already in use

netstat -ano | findstr :5432
# Find PID, then:
taskkill /PID <PID> /F

Or change PostgreSQL to port 5433 in postgresql.conf and update the connection string.

!

CORS error in browser console

In the ASP.NET Core backend's Program.cs, add your frontend origin:

builder.Services.AddCors(opt => opt.AddPolicy("Dev", p =>
    p.WithOrigins("http://localhost:3000")
     .AllowAnyHeader().AllowAnyMethod().AllowCredentials()));
!

SSL certificate error (https://localhost)

dotnet dev-certs https --trust
# Restart Visual Studio and the browser
!

node_modules / pnpm lock issues

rm -rf node_modules
pnpm install
# Or with npm:
npm ci
