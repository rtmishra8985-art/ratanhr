How Bulk Payroll Works
  1. Picks up all active employees in your company.
  2. Uses each employee's latest active salary structure.
  3. Reads attendance (web check-in or Excel upload) for the selected month.
  4. Employees with no salary structure are skipped (counted in "Skipped").
  5. Payslips already generated are skipped unless "Overwrite" is enabled.
